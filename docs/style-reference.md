# Style reference - Emblem of Gundam

Binding for translators and reviewers, after `glossary.md`. Rulings D1-D10 in docs/decisions.md.

## Rulings
- Official English Gundam names and terms (Bandai/Sunrise English releases, the 0079 English dub, the Zeta/0083/08th
  /0080 English subtitles). Mobile suit names as in English model kits: Zaku II, Gouf, Dom, Gelgoog, Gyan, GM, Ball,
  Guntank, Guncannon, Big Zam, Zeong, Acguy, Z'Gok, Gogg, Hygogg, Elmeth.
- Honorifics: `-san`/`-kun`/`-chan` kept; 様 -> Lord/Lady (Lady Kycilia, Lord Garma; a bare キシリア様 addressed
  directly -> "Lady Kycilia"); 閣下 -> Your Excellency; ranks in English: 大将 General, 中将 Lieutenant General,
  少将 Major General, 准将 Commodore (Federation/Titans navy) or Brigadier, 大佐 Colonel (Char is "Colonel Char" in
  0087 flashbacks), 中佐 Lieutenant Commander/Lieutenant Colonel, 少佐 Lieutenant Commander/Major (Char 0079:
  "Lieutenant Commander Char"), 大尉 Lieutenant/Captain, 中尉 Lieutenant (JG)/First Lieutenant, 少尉 Ensign/Second
  Lieutenant, 曹長 Sergeant Major, 軍曹 Sergeant, 伍長 Corporal. Navy forms for ship crews and Zeon space forces,
  army forms for the ground war (08th MS Team, Odessa, Jaburo).
- Era: 宇宙世紀0079 -> "Universal Century 0079" (or "U.C. 0079" in labels); 一年戦争 One Year War; 地球連邦(軍)
  Earth Federation (Forces); ジオン公国 Principality of Zeon; ニュータイプ Newtype; 強化人間 Cyber-Newtype;
  モビルスーツ mobile suit (MS); モビルアーマー mobile armor (MA); コロニー colony; サイド Side.
- Punctuation: 「」 -> "...", 『』 -> '...', …/・・・ -> ..., ！？ -> !?, ー (stretch) -> repeated letter or dash
  ("Nooo--"). Keep `!` count modest (one, or `!!` only for a real scream).
- Numbers: Arabic digits; "0079" keeps its leading zero.

## Narration (stage cards and portrait message windows without 「」)
An essayist chronicler: measured, past tense, dry irony, short declaratives. Keep the narrator's asides ("in the
many retellings", "or so it is said") and the punch of his short closing sentences.
- 簡単に市民が死んだ。 -> "Civilians died easily."
- アムロという稀代の英雄の物語は、ここから始まることになっている。 -> "The story of Amuro, a hero like no other, / is
  supposed to begin here."
- コロニーでの戦闘とは、ようするにそういうものであった。 -> "That, in short, / is what combat in a colony meant."

## Example pairs (approved pattern)
- 「動けっ！　動けよ！」 (Amuro, retreat line) -> `"Move! Come on, move!"`
- 「認めたくないものだな… / 　自分自身の若さゆえの / 　過ちというものを…」 (Char) -> `"It's not something I want / to admit... the mistakes one makes / because of one's youth..."`
- 「やらせはせん！ / 　やらせはせんぞ！」 (Dozle) -> `"I won't let you! / I won't let you do it!"` (continuation line starts with a space)
- 「あの壺をキシリア様に / 　届けてくれよ。 / 　あれはいい物だ…」 (M'Quve) -> `"See that this vase reaches / Lady Kycilia. / It is a fine piece..."`
- Corrected example: 「オートバランサーが / 　効かない…！　ああっ！」 (Sayla) was `"The balancer is broken!"` (dropped
  "auto-", flattened the gasp) -> `"The auto-balancer / isn't working...! Ahh!"`
